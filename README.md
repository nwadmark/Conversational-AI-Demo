# Conversational-AI-Demo

Cisco Customer Intelligence prototype - an interactive AI assistant demo for Wells Fargo with multiple personas (Network Ops, Security Ops, Procurement, and Executive Overview).

## Features
- Futuristic UI with glassmorphism effects
- 4 different persona conversation flows
- Voice input capability
- Custom question handling
- TAC (Technical Assistance Center) support ticket filing

## View the Demo
Open `wells_fargo_network_ops.html` in your browser.
